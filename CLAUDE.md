# CALL-FOR-HUNT

This repo runs a personalised hunt for calls for papers and other academic opportunities for Edward Daniel Simamora (STFT INTIM, Makassar), with about 20% of the effort for his colleague Dr. John Christianto Simon.

- Instructions live only in `kit/` (numbered, dated; later files win). Start with `kit/00 …`, then `kit/01 …`, then `kit/02 …` (baton protocol: Drive is the hand-over point between this repo and Edward's EDS Universe), then `kit/03 …` (each baton ends with the one paste prompt for the next side).
- To run a hunt, use the `/hunt` skill (`.claude/skills/hunt/SKILL.md`).
- Ledger: `ledger/ledger.csv`. Validate with `python3 scripts/ledger.py check`; deadline view with `python3 scripts/ledger.py upcoming`.
- Never delete or overwrite kit files, call cards or reports: add new dated files; retire old ones to `old files/`.
- Never submit, email, register or pay on Edward's behalf.
- Times are WITA (UTC+8).
