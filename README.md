# CALL-FOR-HUNT

A hunt for calls for papers, abstracts, book chapters, grants, fellowships and other opportunities for **Edward Daniel Simamora** (80%) and **Dr. John Christianto Simon** (20%), STFT INTIM, Makassar.

## How to run a hunt

Start a new Claude Code session on this repo and type `/hunt`. The session searches the next six months of calls, writes a call card for each one, updates the ledger, writes a dated report, mirrors the report to the Drive folder CALL-FOR-HUNT, and pushes everything here. It never submits anything.

For pages to be opened (and facts marked VERIFIED), the cloud environment needs broad network access; with a narrow allowlist most calls stay LEAD.

## What is where

| Path | What |
|---|---|
| `kit/` | The instructions: kit v0 (from the Drive "Untitled document") and later addenda |
| `ledger/ledger.csv` | Every call seen: listed, handled, dropped, new |
| `calls/` | One folder per call: call card, and for great calls a first abstract draft and form answers |
| `reports/` | Dated hunt reports |
| `people/` | Edward's and John's profiles |
| `scripts/ledger.py` | `check` validates the ledger; `upcoming` lists deadlines, nearest first |
| `old files/` | Retired versions — nothing is ever deleted |
